## 설계 후보
1. **표시 = NBG2 를 같이 쓰기**: NBG2(16색 셀, B 뱅크 PN 0x5C000)는 게임 중 켜져 있고 거의 비어 있다. 자막 칸(글자 셀)은 B 뱅크 0x5A800(15 KB = 16×16 글자 120자분)에, 맨 아래 2~3줄 지도 칸만 바꾼다. NBG3 새로 켜기는 A 뱅크에 자리가 없어 어렵다.
2. **내용 = ADX 머리에 싣기(RAM 거의 안 씀)**: ADX 머리는 «데이터 시작까지 거리»(u16)가 있어 머리를 늘릴 수 있다 → 클립마다 **미리 그린 자막 그림**(16색 2줄 ≈ 5 KB)이나 글자 코드를 머리 속에 넣는다.
   `ADXB_DecodeHeaderAdx`(0.BIN 에 이름 있음)가 머리를 읽는 순간 그 버퍼에서 VRAM 으로 복사 → RAM 에 글꼴·자막 표를 둘 필요가 없다. ADX.ACX 를 다시 쌓으니 디스크 파일 크기가 바뀐다(ISO 다시 쌓기 필요, +6 MB 정도).
3. (대안) RAM 에 글꼴(쓰는 음절 ~1,000자) + 자막 표(~80 KB) — 빈 RAM 27 KB 로는 부족.
- 표시 시간 = ACX 표의 크기 → 클립 길이. 다른 음성이 시작하면 바꿔 그림.
